# Start here

You only need basic Python, FastAPI route functions and pytest for this lab.

1. Use Python 3.12.
2. Create and activate `.venv` using the README commands.
3. Install requirements.
4. Run `pytest -q`; the starter tests must pass.
5. Run the API and open `/docs` before editing.
6. Create `submission/<your-name>/<task-id>` from `main`.
7. Read your task file and change only allowed files.

The intentionally unfinished endpoints return HTTP 501. That is expected until their matching task is implemented. Never add a database, authentication, external API, secret or unrelated dependency.
